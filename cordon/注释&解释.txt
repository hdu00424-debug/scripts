此脚本主要在耦合k8s 以定时任务的方式进行节点资源检查
动态检查节点的资源使用率，进行封锁
如果有半数以上的节点达到封锁的阈值，则进行资源不足告警
解决上一个脚本的 执行功能粗糙，指标获取不准确的问题


set -euo pipefail
set -e
遇到错误立即退出。当任何命令返回非零退出码时，脚本立即终止。
例外情况：管道中的命令（需要配合 pipefail）、if/while/until 条件中的命令、&&/|| 连接的命令。
set -u
引用未定义变量时报错退出。如果使用了未赋值的变量，脚本会立即报错终止。
例如：echo $UNDEFINED_VAR 会直接报错，而不是静默输出空字符串。
set -o pipefail
管道中任一命令失败则整个管道失败。默认情况下，管道的返回值是最后一个命令的返回值。开启后，只要管道中任意一个命令失败，整个管道就返回失败。
例如：grep "pattern" file | wc -l —— 如果 grep 失败（找不到文件），管道会报错退出。
